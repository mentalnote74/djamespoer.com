Exposure is optional measurement: if the GA tag/session callback is unavailable or the surface disappears before it returns, no exposure is fabricated. It may be timestamped later than its physical appearance; ordered analyses use **recorded** events and must not infer precise rendering latency. Paused/reduced-motion Rigby can be visibly available and counts as exposure; automatic pause/suppression is never dismissal. A saved-off session can later have bring-back, exposure, play and dismissal. Cross-tab localStorage dedup is best effort (simultaneous tabs can race); blocked storage falls back to same-document dedup. Sessions beginning before this release or a consent grant aren't retroactively reconstructed.
