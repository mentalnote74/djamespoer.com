# Security baseline and threat model — 2026-11-16

SCRUM-156. Observed state of production on 2026-11-16 (main `0d4e4ef`), before any accounts, login or payments exist. This records what was checked and how. It is not a claim that the site is secure.

## Evidence (2026-11-16)

**Headers.** `curl -sI` on `/`, `/thingamajob` and `/data/*`: only `Content-Type`, `Cache-Control` and `Server`. No HSTS, CSP, `X-Content-Type-Options`, `Referrer-Policy`, `Permissions-Policy` or framing policy. `public/_headers` sets only cache and `X-Robots-Tag` rules. The Thingamajob Worker returns `Cache-Control: no-store`, a strict CSP (`default-src 'none'; frame-ancestors 'none'`), `Referrer-Policy: no-referrer`, `nosniff` and `noindex`.

**TLS.** A Python `ssl` probe pinned to each version: TLS 1.0 accepted, TLS 1.1 accepted, TLS 1.2 accepted. `http://` → 301 to `https://`. `www.djamespoer.com` does not resolve.

**CORS and origin.** `OPTIONS` from a foreign origin → 405 with no CORS headers. `POST /test/thingamajob/evaluate` with `Origin: https://evil.example` → 403.

**Secrets in bundle.** Grepped the production build for OpenAI, AWS, GitHub and Slack key patterns, PEM headers, and secret names. No hits; the one match was the word "Dusk" in an SVG title. No `*.map` files in the build; `main-*.js.map` on production → 404. No `career-source` or private paths in `dist/`.

**Third-party code.** One third-party script: GA4 `G-WQBYGF4Z8F`, consent-aware and default-on with the internal marker. Fonts are self-hosted (`@fontsource`). Other third-party URLs in bundles are outbound links only.

**Frames.** SWV: a fixed URL, `credentialless`, no `sandbox`. YouTube: `allow="encrypted-media; picture-in-picture; fullscreen"`, `strict-origin-when-cross-origin`.

**Dependencies.** `npm audit`: 0 critical, 5 high, 3 moderate, 1 low. All are in build or dev tooling (`@angular/cli`, `@angular/build`/vite, `wrangler`/miniflare/undici), none in the browser bundle.

**GitHub.** Repo is public. Branch protection on main: none (API 404). Secret scanning and push protection are enabled. Dependabot security updates are disabled. Default workflow permissions are read. `daily-scrum-brief.yml` has `contents: write` and pushes to main, so each brief deploys.

**Data retention.** R2 lifecycle `public-evaluation-90-days` expires `public-evaluations/v1/` after 90 days. D1 rows have `expires_at`, and `worker.ts` `scheduled()` deletes expired rows. But `wrangler.private.jsonc` has no `triggers.crons` (`wrangler.example.jsonc` has `17 4 * * *`), so the job never runs. D1 currently holds 10 attempt rows; the oldest is 2026-10-23.

**DNS.** CAA: none. DS (DNSSEC): none. SPF: `v=spf1 include:_spf.mx.cloudflare.net ~all`. DMARC: none.
